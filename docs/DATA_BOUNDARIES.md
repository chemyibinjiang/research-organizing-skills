# Data boundaries

Publish only reusable source, instructions, blank schemas and clearly synthetic tests.
Never add live profiles, database snapshots, key files, raw email, contact rosters,
travel details, identity/bank records, or judging materials. The ignore file is a
convenience, not a security or anonymization guarantee.

Review the complete staged diff before every push. Search for real addresses,
local account IDs, personal paths, credentials and accidental document exports.
Keep operational evidence outside the clone. Do not upload private data merely
because this repository is private.

Approval to assist with an event does not automatically permit research publication
of correspondence. Any future paper dataset needs its own permissions and privacy
review. Prefer synthetic examples; label them as such rather than field evidence.

No external sending, shared-document editing or credential acquisition is authorized
by installing a skill. Permission must come from the current user task.
