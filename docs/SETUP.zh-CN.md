# 使用说明

这不是“一键自动办会”，而是两项可复用的操作技能和一组空白记录模板。
它们帮助读取指定微信会话、整理邮件及准备回复，重要决定和发送操作仍由人确认。

## 仓库里有什么

- `skills/wechat-local-reader`：限定会话和时间读取，区分原话、引用和转发，追溯附件。
- `skills/email-correspondence`：查收件和已发送、记录进展、准备附件邮件、批准后发送并核验。
- `templates`：项目当前状态、专题交接、联系人和邮件记录的空白模板。
- `tests` 和技能内的测试：仅合成数据，不会连接真实邮箱或读取微信。

## 怎么开始

1. 先看 [英文安装说明](SETUP.md)，配置 Python 3.11 和依赖。
2. 执行 `python scripts/run_tests.py` 跑离线测试。
3. 执行 `python scripts/install_skills.py` 预览；确认后加 `--apply` 安装。
4. 在仓库外配置自己的账号、文件路径和私有输出目录。已有配置不能整份覆盖。
5. 从一项小的只读任务开始，例如“看这个项目群昨天以来有哪些变动和待办”。

已有不同版本的技能不会被安装器覆盖。微信需要本人授权的数据和已有受保护密钥；
本仓库不提供获取或恢复密钥的功能。没有条件时，使用获得授权的界面或导出方式。
邮箱要用本人账号及合规客户端凭据，不能借用其他人的密码。

## 使用时务必区分

- 已起草、已批准、已发出、已核已发送副本、对方已回复、事情已完成，是不同状态。
- 旧消息的引用不是新的决定；表格生成不等于已经发给会务，更不等于现场落实。
- 发信前核收件人、抄送、正文、附件及最新回信。发送结果不明确时不要直接重试。
- 个人信息、行程、评审材料、聊天、邮箱、密钥都不能上传到这个仓库。
- 本地脚本处理不等于整个AI过程均在本地；使用外部模型处理信息要符合单位要求。

仓库初始为私有，同事需由仓库所有者授予访问权限。尚未确定开源许可证，暂不要公开转发。
这是个人整理的通用工作流，不代表机构授权或背书；会议原始记录和论文草稿没有放在仓库里。
