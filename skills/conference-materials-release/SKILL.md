# Conference Materials Release

## Establish the Working Copy

Identify the current approved programme, live human-edited documents, name roster,
award order and source of each last-minute change. Read the files, not just their
names. Keep source, review copy and delivery copy distinct. Do not regenerate a
user-edited script from an older export or reorder a deck without authorization.

## Compose for the Actual Event

- Host scripts: introductions based on the speaker's verified bio, title and
  abstract; brief achievements only when supported. Match the agreed English
  terminology and tone. Estimate duration using a stated speech-rate assumption,
  not an invented personal speaking speed. Leave scientific remarks to speakers.
- Run sheets: for every small step, identify time, speaker/host, stage action,
  microphone/slides/video, responsible operator and handover cue. Use confirmed
  award order and presenters. Questions only if time allows when no Q&A is booked.
- Roundtables: retain the approved question version; optional follow-ups belong
  in an appendix. Make speaking/seat order explicit. A full-audience photo cue
  differs from a panel-only photo and belongs to the designated host.
- Seating: fix the view direction, blocks, reserved host positions, accessibility
  and confirmed attendance before filling seats. Keep protected constraints fixed
  when balancing the rest. A tentative attendee needs an explicit status.
- Slides: track owner, expected file, received version, media/fonts, playback
  operator and on-site test. Receipt is not successful playback. Establish a
  deadline and fallback for late files without promising unapproved facilities.
- Review packets: give each reviewer the approved rules, group/assignment list,
  meeting point/time, result-return instruction and current change sheet. Keep
  display-only and withdrawn entries distinct from eligible entries.

Use the available Word, spreadsheet, slide or PDF tools for creation and visual
verification. Do not claim to have rendered or tested something that was only
text-extracted. Preserve complete faces in photo layouts and check page breaks,
tables, names/diacritics, fonts and printable margins.

## Apply Corrections Once, Propagate Deliberately

Map a correction to the roster, slides, host script, certificate or reviewer form
that actually uses it. Do not change unrelated titles or names. Record obsolete
versions privately. Already printed copies may require a replacement page or
erratum; specify exactly which page/version, and only mention an old print run
when the recipient knows it exists.

## Package for the Receiver

Use [the print manifest](assets/print-manifest.template.csv). Confirm copy counts,
paper size, color, duplex, page ranges and spare copies with the organizer. Spares
should have a stated purpose; do not invent a universal percentage.

Create a clean delivery folder containing only authorized final PDFs and a manifest
with exact filenames, versions, page counts and file hashes. Exclude editable drafts,
temporary renders, private contact/finance data and unrelated files. For poster
production remove unwanted print metadata only when requested and verify the result.
Keep archive creation and verification separate; reopen the archive and compare its
members to the manifest. Do not delete source documents to make the package tidy.

Draft a short vendor message listing each item and quantity. Track prepared,
approved, sent, received and printed separately; a ZIP on disk is not a print order.
Also hand off the slide deck and playback test to the named venue technician.
